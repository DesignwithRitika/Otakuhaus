# Otakuhaus
A four-month branding project building OtakuHaus from scratch, covering social media campaigns, website visuals, packaging, merchandise, and mascot design for a youth-focused streetwear brand.


Project Overview
OtakuHaus is an early-stage apparel startup created for North Indian middle-class youth—a community balancing expectations, academic pressure, hidden fears, and unspoken dreams.
The project began from the ground up, with no established social media presence, defined brand story or visual direction, website or digital identity, branded merchandise, or packaging system. Working closely with the founder, I helped shape a premium, trust-driven streetwear system within an intensive four-month timeline.

Project Details
- Project: OtakuHaus
- Duration: 4 months
- Focus: Brand visuals, social media, website visuals, packaging, merchandise, and mascot design
- Campaign concept: The Voices of the Unheard

The Challenge
Build a cohesive visual and digital presence from scratch for a new streetwear brand, creating a recognizable system across online content, website visuals, packaging, and merchandise.
